# 宝宝日记

极简录入：首屏上大半留白 + 正中文字/语音；下方「截至目前」多维汇总。  
页面可滚动，总结不锁死在一屏里。  
支持口语如：刚才尿了一次、上午拉了两次、喂了一次奶（可不说 ml）。

## 配置

编辑 `baby-chat-config.js`：

- `DASHSCOPE_API_KEY`：百炼（网页即时 ASR/LLM）
- `GITHUB_TOKEN`：写仓库

## 使用

1. 打开页面，正中说话或打字 → 立刻解析入库，中间闪一下「已记：…」
2. 底部看今日喂奶 / 小便 / 大便等汇总；点底部可改明细
3. 每晚 20:00 云函数推微信（需 `PUSHPLUS_TOKEN`）

## 云函数

`cloud-function-baby-chat/` 只做晚间总结，改完需整包重传。
