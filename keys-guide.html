密钥 续期指引

← 总导航

本页只写「叫什么、用在哪、去哪申请、过期会怎样」。不要把真实 Key / Token 写进这个 HTML 或提交到仓库。 网页里的 GitHub Token 目前是拆开写在 JS 里的；云函数一律走环境变量。

过期最常见：GitHub PAT（网页盯一下写不进去 / 发现页 To Watch 失败 / 云函数 401）。 换新 Token 后要同时改前端几个文件 + 四个云函数环境变量，漏一个就会半边还能用、半边挂。

3. GitHub PAT（改一次要改齐）

仓库：betterma/pages。权限：能读写仓库文件即可（classic 勾选 repo；fine-grained 给 Contents Read and write）。

  1. 打开 Tokens → Generate new token。
  2. 到期日自己记在日历上（GitHub 到期前会发邮件）。
  3. 新 token 填到下面「前端」和「云函数」两处，旧的在 GitHub 里 Revoke。

前端（拆成两段字符串，避免整段出现在仓库检索里）：

  • watch-favorites.js → 币安观察 kline.html、冲榜 watch.html、Range100
  • okx/favorites.js → OKX 自选 K 线
  • trade-sim.js → 模拟交易面板
  • getcoininfo.html → Solana 获取详情（To Watch / To All 写 GitHub）
  • eth/getcoininfo.html → Robinhood 获取详情

云函数环境变量（名称都是 GITHUB_TOKEN，可用 GH_TOKEN 别名）：

  • cloud-function-monitor — 写瘦身 watch-data.json
  • cloud-function-notify — 钉、日志、企微文案、破点高
  • cloud-function-okx — 读 okx/favorites.json
  • cloud-function-trade — 读写 trade-bot-state.json

过期表现：页面提示读取/写入 GitHub 失败、401；自动盯不更新；发现页 To Watch 报写入失败。

5. 各 Key 申请步骤（过期重做）

Birdeye（Solana 详情）

  1. 打开 Birdeye API 文档，按文档注册 / Dashboard 创建 Key。
  2. 只改 getcoininfo.html 里的 API_KEY（请求头 X-API-KEY），不要提交到公开讨论区。
  3. 免费档大约 60 rpm，页面已按约 1 秒一个地址节流。超限会大面积查询失败、表格标红。

PushPlus

  1. pushplus.plus 微信登录 → 一对一推送 → 复制 token。
  2. 只放 notify 云函数环境变量 PUSHPLUS_TOKEN，不要写进仓库。
  3. 暂时不用微信：设 AUTO_PIN_PUSHPLUS=0（否则 notify 会直接报缺 token）。

企业微信机器人

  1. 进目标群 → 群机器人 → 添加 → 复制 Webhook URL（含 key=）。
  2. 环境变量：WECOM_WEBHOOK_PINS / WECOM_WEBHOOK_POSITIONS，或旧的总开关 WECOM_WEBHOOK_URL。
  3. 当前产品默认盯一下/持仓/破点高只写网页；自动盯企微要显式 AUTO_PIN_WECOM=1。

OKX Onchain OS

  1. 在 OKX 开放平台创建 API Key，记下 Key、Secret、Passphrase 三样（Passphrase 只在创建时出现一次）。
  2. 填入 okx 云函数：OKX_API_KEY、OKX_SECRET_KEY、OKX_PASSPHRASE。
  3. K 线走 GET /api/v6/dex/market/candles（Basic 月免费约 10 万次）。额度用尽是 HTTP 402 + x402（要按次付钱），不是 401。到期/额度满：自选页 K 线停更、沿用旧 OBS 缓存；下月 1 号额度重置，或到 Onchain OS 看配额/订阅。

华为云 OBS

  1. 华为云 → 统一身份认证 IAM → 访问密钥 → 新建 AK/SK。
  2. monitor 与 okx 云函数都填：OBS_ACCESS_KEY（或 OBS_AK）、OBS_SECRET_KEY（或 OBS_SK）。
  3. 默认桶 mpctest，地域 obs.cn-north-4.myhuaweicloud.com。AK 不要带空格或「OBS」前缀。
  4. 过期表现：观察池 OBS 回落失败、OKX K 线缓存写不进去。

6. 换 GitHub Token 检查清单

  1. 前端 5 个文件里的拆分 Token 已替换并推送到 main（Pages 才能用新的）。
  2. monitor / notify / okx / trade 四个函数环境变量已改，保存后各手动触发一次。
  3. 浏览器强刷：币安观察能同步钉；Solana / Robinhood 详情能 To Watch；OKX 能改自选。
  4. GitHub 旧 PAT 已 Revoke。
