# 跳跳提示（Jump Hints）规格 v0.2

**已改需求：不做自动买卖，只做即时提示。**  
原「跳跳交易 / 独立交易云函数」取消；逻辑在 **kline 页面** 持仓旁的「跳跳」浮窗完成。

---

## 目标

在钉子页头部增加 **跳跳浮窗**（与「持有」并列）：

- 列出**当前时间所在 4h 窗、此刻仍符合条件**的币（可多个）
- 每条展示 **通知页同款 K 线**
- K 线须标出 **自动盯点**（盯价水平线 + 盯时竖线/圆点）；通知页既有图一并补上

不写实盘订单；不新建交易云函数。

---

## 入选条件（须同时满足）

1. 在 **盯一下** 中，且 `source` ∈ `auto-cloud` / `auto-rising` / `auto-rewarm`（自动盯）
2. 在 **钉子** 中，便签可解析出有效 **便签水位**（`note` 价 &gt; 0）
3. **相对便签水位非红、为蓝**：现价（ticker，否则最新 4h 收）**&gt; 便签水位**
4. **当前 4h 窗上涨**：`hasWindowGain(symbol, 4h)`（与观察池窗涨一致）
5. 仅 **crypto** 页；bstock 不做

排序：相对水位涨幅升序（越「刚翻蓝」越靠前），其次 24h 成交额/涨幅。

---

## UI

- 入口：钉子头右侧，持有旁「跳跳」按钮
- 浮层：列表卡片（名称、水位、现价、相对水位%、窗涨）+ `canvas` K 线
- 打开时即时重算列表并拉/画 K；可手动刷新
- 点名称：跳到钉子/主卡（与通知页 jump 一致）

---

## K 线绘制（对齐通知页 + 盯点）

调用现有 `drawKline`：

| 参数 | 值 |
|---|---|
| `pinPrice` / `pinnedAt` | 自动盯的盯价与盯时（**通知页此前漏传，需补**） |
| `alertMark` | `{ price: 便签水位, fromAt: noteAt }` |
| `deltaMark` | `{ fromOpenTime: 当前4h窗起点, notifyPrice: 便签水位 }` → 窗内相对水位染蓝/红 |

根数/周期与通知页一致：`4h` × 约 18 根。
