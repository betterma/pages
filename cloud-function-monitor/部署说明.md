# 监控云函数（当前唯一需要的函数）

## 架构

```
新加坡事件函数 monitor-fn（定时 0/15/30/45）
  → 拉币安行情
  → 写 OBS：watch-data.json

浏览器 watch.html / kline.html
  → 读 OBS：watch-data.json（行情）
  → 读/写 GitHub：watch-favorites.json（收藏）
```

已放弃：HTTP 函数、APIG、收藏写 OBS。

## 部署包

目录：`cloud-function-monitor/`

| 文件 | 作用 |
|------|------|
| `index.js` | 入口 `index.handler` |
| `monitor.js` | 监控逻辑 |
| `obs-client.js` | OBS 读写 |
| `monitor-fn.zip` | 可直接上传 |

## 配置

- 类型：事件函数  
- 区域：新加坡（或能访问币安的区域）  
- 超时：60s  
- 内存：256MB  

环境变量：

```
OBS_ACCESS_KEY=...
OBS_SECRET_KEY=...
OBS_BUCKET=mpctest
OBS_ENDPOINT=obs.cn-north-4.myhuaweicloud.com
```

定时 Cron：

```
0 0,15,30,45 * * * *
```

## 注意

监控代码**只维护本目录**，不要再在仓库根目录放 `monitor.js`。  
GitHub Actions 旧 workflow 已移除，定时任务只跑华为云函数。
